# 阶段 8 · 外行星、现代技术与流派地图

> 第 316–350 天（5 周，35 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

学会现代占星新增的天体和技术（天王、海王、冥王、凯龙、小行星、中点、谐波、赤纬），了解恒星黄道与印度占星的基本差别，梳理近现代占星史和流派地图；能在古典与现代之间说清自己的取舍。

## 学完能讲清

- [ ] 外行星的发现史和运行周期；象征是在发现后"商定"出来的。
- [ ] 现代守护（天王守水瓶、海王守双鱼、冥王守天蝎）的争议。
- [ ] 世代行星为什么对个人意义有限。
- [ ] 中点、汉堡学派 90° 盘、谐波、赤纬与出界的原理。
- [ ] 印度占星的主要不同（恒星黄道、整宫、月宿）。
- [ ] 近现代占星史与主要流派；古典复兴运动。

# 阶段 7 · 本命盘综合解读：方法与大量案例

> 第 253–315 天（9 周，63 课）｜ 返回 [总览 plan.md](../plan.md)
>
> 从这一阶段起，"案例日"大量增加。每周节奏改为：3 节方法课 + 2 节案例课 + 1 天写盘 + 1 天讲解。

## 阶段目标

把前六个阶段的零件组装成一套可复用的解盘方法，按人生主题（性格、心智、职业、财富、关系、家庭、健康、信仰）逐一练习，读 20 张以上案例盘；能写出有依据的星盘报告，并能口头讲解。

## 学完能讲清

- [ ] 解盘七步流程，以及"多重证词"的加权原则。
- [ ] 每个人生主题看哪些宫、哪些行星、哪些点，为什么。
- [ ] 气质（冷热干湿）计算的方法与局限。
- [ ] 同一张盘的古典读法与现代心理读法的差别。
- [ ] 拿到陌生的盘，讲 15 分钟，每句话能说出依据，并区分"盘面事实"和"我的解读"。

## 案例日的 20 分钟

温习 3 分钟 → 盘面事实（App 自动列出，飞飞核对）4 分钟 → 推导解读（按流程逐步写要点）8 分钟 → 对照参考解读与传记事实 3 分钟 → 记一条心得 2 分钟。

## 本阶段问答库新增（节选）

- 空宫是不是代表那方面没有？（看宫主星）
- 为什么同一张盘不同占星师读出来不一样？（方法、宫位制、取舍、风格）
- 能从星盘看出一个人会不会离婚吗？（伦理与证据）
- 星盘和"性格测验"有什么区别？

## 案例来源规则

只用 Rodden 评级 AA 或 A 的出生数据，优先已故历史人物；每张盘入库前核对两个独立来源；只存出生数据和公开传记事实。案例库可扩展，App 内显示来源。

## 本阶段关键动效

解盘七步的"进度星路"（每步点亮）、证据加权的天平（证据卡放上去，天平倾斜）、主题高亮（选"职业"，盘上相关宫和行星亮起，其余变暗）。

# 阶段 3 · 尊贵与接纳：行星住进星座

> 第 92–133 天（6 周，42 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

理解"行星守护星座"背后的对称结构（世界之盘），然后逐层学完古典尊贵体系：守护、入旺、三分性、界、十度，以及落陷、入弱、游走、互容与接纳；能给任意行星做尊贵评估，并从中读出"它有多少资源"。

## 学完能讲清

- [ ] 不看表现场推出七颗行星的守护星座，并用相位检验对称。
- [ ] 落陷、入弱分别是守护和入旺的对宫；入旺的度数来源不明（巴比伦），明说。
- [ ] 三分性主星的昼夜分配；多罗修斯、托勒密、李利三套的差别。
- [ ] 埃及界的结构、各行星总度数 = 行星"大年"，以及界的来源争议。
- [ ] 十度按迦勒底顺序从火星开始，36 = 7 × 5 + 1 导致"火星连两次"。
- [ ] 互容、接纳、定位星链、最终定位星。
- [ ] 尊贵 ≠ 吉凶：尊贵讲资源与能力，吉凶讲本性。

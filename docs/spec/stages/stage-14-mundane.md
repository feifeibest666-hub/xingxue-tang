# 阶段 14 · 世俗占星

> 第 554–588 天（5 周，35 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

学习占星如何谈论国家、城市、时代：入境盘、木土大会合、日月食、外行星周期、国家盘与事件盘、占星地图；用历史案例理解它的方法，同时清醒地看到事后解释和预言失败的历史。

## 学完能讲清

- [ ] 白羊入境盘（春分盘）及四季入境盘的读法。
- [ ] 木土大会合约 20 年一次、约 200 年在同一元素内的推导（会合周期计算 + 每次前进约 243°）。
- [ ] 国家盘的时刻选择问题（争议），以中美两国为例。
- [ ] 占星地图的几何原理（每条经线上的天顶不同）。
- [ ] 世俗预言失败史和事后解释偏差。

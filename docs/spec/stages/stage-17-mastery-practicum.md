# 阶段 17 · 大师实践与毕业

> 第 645–700 天（8 周，56 课）｜ 返回 [总览 plan.md](../plan.md)
>
> 前 16 个阶段学完全部技术；这最后 8 周全部用来"用"和"讲"。每天仍是 20 分钟。

## 阶段目标

通过大量综合案例巩固全部技术；把知识组织成能讲给别人听的课程；完成毕业项目：一份完整星盘报告书、一份年度预测与回顾、一套 5 讲的"占星原理"讲解录音，以及最终答辩。

## 学完能讲清

- [ ] 用古典 + 现代方法完整读一张陌生的盘，30 分钟以内讲完并说出每一步依据。
- [ ] 为一个人做一年的综合预测（小限 + 释放 + 法达 + 行运 + 回归），并写清不确定性。
- [ ] 判断卜卦盘、设计一次择日、校正一个出生时间。
- [ ] 从天球讲到预测技术，连续讲 60 分钟（分 5 讲），每个环节标出事实、推导、传统、约定、争议。

## 毕业评分表（讲解类通用）

| 项目 | 标准 |
|---|---|
| 依据 | 每个结论都说出来源 |
| 分层 | 标出事实、推导、传统、约定、争议 |
| 不跳步 | 推导链完整 |
| 类比 | 至少一个恰当类比，并说出它在哪里不成立 |
| 诚实 | 不夸大预测力，提及证据状态 |
| 清楚 | 外行也能听懂主线 |

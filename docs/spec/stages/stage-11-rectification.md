# 阶段 11 · 生时校正

> 第 456–476 天（3 周，21 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

在出生时间未知或不准时，用人生事件反推出生时间；掌握主要校正方法（小限/行运到轴、推运到轴、主限、黄道释放、历史上的赫尔墨斯法则和 animodar），并学会评估校正结果的不确定性，避免自欺。

## 学完能讲清

- [ ] 为什么需要校正；出生时间记录常见的误差来源。
- [ ] 校正的核心逻辑：重大事件应伴随四轴被触发 → 反推四轴 → 反推时间。
- [ ] 至少三种方法的步骤。
- [ ] 为什么校正结果需要多事件交叉、盲测，以及它的局限。

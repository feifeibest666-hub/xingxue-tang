# 阶段 12 · 卜卦占星

> 第 477–525 天（7 周，49 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

学会为一个具体问题起盘并判断：问题的"诞生时刻"、问者与所问之事的代表星、判断前的考量、完成与阻碍的各种形式、时间与方位判断；读完李利等经典例题，并建立自己的卜卦验证日记。

## 学完能讲清

- [ ] 卜卦的基本假设："问题被理解的一刻"也有一张盘（约定）。
- [ ] 问者、所问之事的代表星（转宫）；月亮作为共同代表。
- [ ] 判断前考量（上升过早过晚、月亮空亡、燃烧途径等）的含义与争议。
- [ ] 完成的方式：入相、光线传递、光线集中；阻碍：禁止、反悔、挫败。
- [ ] 时间与方位的推算规则（推导 + 约定）。
- [ ] 卜卦伦理：一问一事、不问健康诊断、真诚提问。

# 阶段 15 · 关系占星与咨询实务

> 第 589–623 天（5 周，35 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

掌握两张盘的比较方法（比对盘、组合中点盘、戴维森盘），以及做一名负责任的占星师需要的实务：收集数据、咨询结构、语言、伦理、报告写作、讲解给不同听众；通过角色卡模拟咨询。

## 学完能讲清

- [ ] 比对盘的方法（行星落对方宫位、交叉相位、主星接纳）。
- [ ] 组合中点盘与戴维森盘的计算差别。
- [ ] 太阳星座配对为什么是极粗的简化；大样本研究没有找到稳定关联。
- [ ] 咨询的结构、语言（倾向而非宿命）、伦理底线、转介。

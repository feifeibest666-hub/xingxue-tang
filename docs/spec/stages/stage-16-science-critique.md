# 阶段 16 · 科学、历史与批判思考

> 第 624–644 天（3 周，21 课）｜ 返回 [总览 plan.md](../plan.md)
>
> 一位真正的"大师"既能把占星讲清楚，也能把它的证据地位讲清楚。这一阶段不是要否定前面学的内容，而是把"讲得清"补完整。

## 阶段目标

了解对占星做过的主要科学检验及结果，理解"感觉准"的心理机制，了解占星的辩护论点和它们的强弱，梳理天文学与占星分离的历史；形成自己平衡、有证据的立场，并能在辩论中表达。

## 学完能讲清

- [ ] 什么是可检验的预测，为什么双盲很重要。
- [ ] Carlson（1985，《自然》）、时间双胞胎研究（Dean 与 Kelly，2003）、戈奎林"火星效应"及其争议的要点。
- [ ] 巴纳姆/福勒效应、确认偏差、冷读、自我实现。
- [ ] "占星是象征语言/卜筮"等辩护的内容与局限。
- [ ] 天文与占星在 17 世纪前后分离的历史。

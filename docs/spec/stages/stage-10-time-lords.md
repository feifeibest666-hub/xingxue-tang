# 阶段 10 · 预测技术 II：古典时间主星与主限

> 第 400–455 天（8 周，56 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

掌握希腊化、波斯、中世纪的核心预测技术：年小限、法达、黄道释放、主限（含界推进），理解"时间主星设定主题、行运与主限触发事件"的层级结构；能综合多技术做年度预测，并清醒地认识"技术越多越容易命中"的统计陷阱。

## 学完能讲清

- [ ] 时间主星的概念：人生按时期交给不同行星"值班"。
- [ ] 年小限：上升每年前进一个星座；年主星；与"本命年"的结构相似和来源不同。
- [ ] 法达：日盘与夜盘的顺序、各段年数（共 75 年），以及交点位置的争议。
- [ ] 黄道释放：从福点/精神点出发，星座期长 = 主星的"小年"；层级、松绑、巅峰期。
- [ ] 主限：周日运动把一点转到另一点所需的赤经弧；时间钥匙（托勒密 1°=1 年、奈伯德）。
- [ ] 各技术的层级关系和取舍；伦理：寿命技术只讲历史。

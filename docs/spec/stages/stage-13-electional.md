# 阶段 13 · 择日占星

> 第 526–553 天（4 周，28 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

学会为一件事选择开始的时刻：择日的基本原则（月亮、上升、命主星、事项宫）、按事项的规则、与本命盘结合、行星时，以及用工具扫描时间窗口；清楚择日的极限、伦理与心理作用。

## 学完能讲清

- [ ] 择日的逻辑："给事情选一个出生时刻"（约定）。
- [ ] 择日的极限：完美的时刻几乎不存在，且受本命盘限制。
- [ ] 强化月亮、上升与命主星、角宫避凶星等基本规则。
- [ ] 水逆是否需要回避：事实（每年约 3–4 次，约占全年 19%）与流行说法的区分。

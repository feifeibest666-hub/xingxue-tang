# 阶段 9 · 预测技术 I：行运、回归与推运

> 第 351–399 天（7 周，49 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

理解"本命盘是承诺，时间技术决定何时"的逻辑；掌握现代最常用的预测技术：行运、日月食与月运、太阳/月亮/行星回归、次限推运、太阳弧；区分"真实天象"和"象征换算"；建立预测日记，用可检验的方式记录。

## 学完能讲清

- [ ] 行运是真实天象，推运和太阳弧是象征换算。
- [ ] 土星回归（约 29.5 岁）、木星回归（约 12 岁一次）、天王星对冲（约 42 岁）等周期从轨道周期直接推出。
- [ ] 行运的速度层级；外行星"三次过点"。
- [ ] 太阳回归盘的计算与地点之争。
- [ ] 次限推运"一天 = 一年"的来源（约定）；推运月亮约 27–28 年一圈。
- [ ] 如何写出可以事后检验的预测。

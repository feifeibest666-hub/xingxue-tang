# 阶段 4 · 相位：圆上的角度几何

> 第 134–168 天（5 周，35 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

把相位理解为"圆的等分"，从第 1 阶段的星座关系网直接推出五个托勒密相位的性质；学完古典相位理论（整宫相位、不合意、容许度与光体、入相出相、压制、围攻、吉化凶化、映点）和现代扩展（次要相位、格局、谐波）。

## 学完能讲清

- [ ] 五个托勒密相位的角度、图形，为什么恰好是这五个。
- [ ] 三分、六分"和谐"，四分、对分"紧张"的推导（元素、极性、模式）。
- [ ] 整宫相位与度数相位；不合意（30°、150°）的古典含义。
- [ ] 容许度的两种体系（按行星光体 vs 按相位），都是约定。
- [ ] 入相/出相、完成、压制、围攻、吉化凶化。
- [ ] 映点的几何来源（等赤纬 = 等昼长）。
- [ ] 次要相位、相位格局、谐波的来源（开普勒以后），标为现代约定。

## 本阶段问答库新增（节选）

- 四分相一定是坏事吗？（紧张 ≠ 坏；传统也视之为推动力）
- 容许度到底取多少？（没有标准答案；App 设置里可选）
- 古典占星为什么不用 150°？（不合意：不在同一个"看得见"的关系里）
- 为什么相位要分入相出相？（同一相位，正在形成和已经过去含义不同）

## 本阶段关键动效

相位画线（拖动吸附，显出正多边形）、容许度发光带、入相出相的追赶动画、围攻夹击、映点镜像翻折、谐波（圆按 n 等分的花形图）。

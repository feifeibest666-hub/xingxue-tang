# 阶段 5 · 宫位与四轴：把一天的旋转切成十二份

> 第 169–217 天（7 周，49 课）｜ 返回 [总览 plan.md](../plan.md)

## 阶段目标

星座来自"一年"，宫位来自"一天"。从地球自转推出上升点、天顶和四轴；理解斜升、纬度和出生时间精度；学会各大宫位制的几何与历史，诚实讲清宫位制之争；推出十二宫的含义来源（相位关系、位置象征、喜乐）和宫主星系统。

## 学完能讲清

- [ ] 上升点、天顶、下降点、天底的定义；天顶 ≠ 头顶正上方。
- [ ] 为什么出生时间差 4 分钟上升点约差 1°，差两小时就可能换星座。
- [ ] 快升慢升对上升星座分布的影响；高纬度问题。
- [ ] 宫位为什么逆时针编号，而天体每天顺时针穿宫。
- [ ] 整宫、等宫、波菲利、普拉西度、科赫、雷氏、坎帕纳斯的分法和理由；为什么普拉西度在极圈附近失效。
- [ ] 2、6、8、12 宫为什么在传统里"不好"（与上升不合意）；喜乐宫的对称结构。
- [ ] 宫主星把宫和行星连起来的规则；命主星。

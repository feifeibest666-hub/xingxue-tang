# 阶段 2 · 七颗古典行星：会动的天体

> 第 43–91 天（7 周，49 课）｜ 返回 [总览 plan.md](../plan.md)
>
> 先讲每颗行星**怎么动**（天文），再讲古人为什么从这种运动里读出这种**意义**（传统），每一步标明推导和约定。

## 阶段目标

认识肉眼可见的七个"行星"（古人把日月也算作"游走的星"）：它们的运动规律、可见性、速度、逆行，以及从运动推出的象征；推出迦勒底顺序和星期顺序；理解吉凶、昼夜、阳阴这些古典分类的内部逻辑。

## 学完能讲清

- [ ] "行星"的古义；占星为什么用地心视角。
- [ ] 月相 = 日月夹角；恒星月和朔望月为什么不同。
- [ ] 水星、金星为什么离太阳不远（最大距角约 28° 和 47°），为什么永远不会与太阳对冲。
- [ ] 逆行是超车造成的视觉效果；各行星逆行的频率和时长从会合周期推出。
- [ ] 迦勒底顺序从何而来；如何用"行星时"推出"日月火水木金土"的星期顺序。
- [ ] 每颗行星的核心象征，以及它和运动特征的联系。
- [ ] 吉凶（冷热干湿）、昼夜、阳阴行星的划分逻辑；哪些是约定。
- [ ] 光束下、焦伤、日核、偕日升落的天文含义与传统用法。

## 本阶段问答库新增（节选）

- 水逆真的会让手机坏、合同出问题吗？（天文事实 + 现代流行说法的来源 + 没有证据）
- 为什么太阳和月亮也算"行星"？
- 金星为什么被叫作"启明星"和"长庚星"？
- 木星每年换一个星座，和本命年有关系吗？（结构相似：都是 12 年；来源不同）
- 星期的名字真的是从行星来的吗？（是；日语至今用日月火水木金土曜日）
- "大凶星"是不是一定带来坏事？（传统里的"凶"是性质，不是命运判决）

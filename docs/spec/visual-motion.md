# 视觉与动效方向

> 返回 [总览 plan.md](plan.md)

## 1. 概念："纸上星图"

一本古老的手绘星图册，和真实的夜空叠在一起。

- **读的时候是纸**：课程正文在暖色纸面上，铜版画式细线插图，金色点缀，安静、适合阅读。
- **看天的时候是夜**：模拟器、星盘、动画在深靛蓝夜空上，星星微微闪烁，金线在上面画出几何。
- 两种表面的切换本身就是动效：纸面"卷起"，露出下面的夜空。
- 气质：好奇、轻盈、有一点玩心，但不幼稚；不用卡通贴纸，不用廉价渐变。

## 2. 配色

| 名称 | 色值 | 用途 |
|---|---|---|
| 星图纸 | `#f3eee2` | 主背景 |
| 纸面浅 | `#faf7ef` | 卡片 |
| 墨 | `#1f1d24` | 正文、主按钮（主按钮用墨黑，与易学堂一致） |
| 墨淡 | `#6f6a75` | 次要文字 |
| 夜空 | `#141a2e` | 模拟器背景 |
| 夜空浅 | `#232b45` | 夜空上的卡片 |
| 星白 | `#f6f1e4` | 夜空上的文字和星 |
| 金箔 | `#c2a05a` | 强调、几何线、当前位置 |
| 星蓝 | `#5b7fa8` | "天文"标签、黄道/赤道线 |
| 青绿 | `#3f6e66` | "推导"标签、答对、完成 |
| 朱红 | `#b0442f` | "约定/争议"标签、错题；少量使用 |

**四元素色**（只在讲元素时用，饱和度压低）：火 `#c4633f`、土 `#8b7a4e`、风 `#8aa9b8`、水 `#3f6f8f`。

**三模式用形状而不用颜色**：开创 = 向外的尖角，固定 = 方块，变动 = 波浪线。颜色只编码元素、形状只编码模式，一个星座图标同时带两种信息。

**吉凶不用红绿**：吉星和凶星用实心/空心区分，避免"红 = 坏"的暗示，也照顾色弱。

## 3. 字体

- 标题和正文：系统宋体栈（`'Songti SC','STSong','Noto Serif CJK SC','Source Han Serif SC', serif`）。
- 界面小字：系统无衬线。
- 度数：等宽数字（`font-variant-numeric: tabular-nums`），"15°23′"对齐。
- 星座/行星符号：**自绘 SVG 符号**。不用 ♈ ♉ 等 Unicode 字符，因为它们在 iPhone 和安卓上会变成彩色表情图标。自绘符号统一线宽，还能做"一笔一笔写出"的动画。
- 不使用 Google Fonts 或任何第三方字体。

## 4. 动效原则

1. **每个动效都教一个概念**，不做纯装饰动画。
2. **物理诚实**：速度比例尽量真实；需要夸张时（如放大倾角）在角落标"示意，已放大"。
3. **可拖动的时间**：大多数天文动画有时间滑块，可以自己拖着看。
4. **慢而柔**：天体运动用平滑缓动；只有打卡、答对这类奖励时刻才用弹簧。
5. 尊重"减少动态效果"（`MotionConfig reducedMotion="user"`），此时改为淡入淡出和静态示意图。

# App 结构设计

> 返回 [总览 plan.md](plan.md)

## 1. 底部五个标签

| 标签 | 内容 |
|---|---|
| **今日** | 今天的课（大图卡，标出"新课/实践/案例/复盘"）、今日温习数量、连续打卡星、待补的课、"今日天象"小卡、学习地图缩略、打卡星空日历 |
| **学程** | 学习地图（17 个阶段），点进去是每个阶段的课表；右上角切换"知识星网" |
| **星图** | 工作台：①天空模拟器 ②星盘（本命/行运/回归/推运/比对）③技术面板（小限、法达、黄道释放、主限、卜卦考量、择日扫描）④星典（星座、行星、相位、宫位、尊贵表、特殊点、恒星）⑤案例库 |
| **温习** | 间隔重复、错题本、推导练习、预测日记 |
| **问答** | 问答库、我的疑问本、讲解练习与录音 |

上课页、欢迎页隐藏底栏（沉浸模式），与易学堂一致。**全部课程随时可学，不上锁**；"今日一课"只是建议顺序（第一节未完成的课）。

## 2. 首次进入

欢迎页：星空大图，标题"星学堂"，黑色主按钮"从这里开始 · 第 1 天"，三条承诺（"每个结论都告诉你为什么" / "事实和传统分开讲" / "每天 20 分钟，两年成为能讲透的人"），下面是学习地图。另有"我已经学过一些，直接进入"。

## 3. 四种课

每天一课、20 分钟。按周循环，前几个阶段是"5 新课 + 1 实践 + 1 复盘"，从第 7 阶段起加入大量案例课。时间分配见 [plan.md](plan.md#每课-20-分钟怎么分)。

| 类型 | 内容 | 结尾 |
|---|---|---|
| **新课** | 封面 → 课程屏（见下表）→ 3–5 道题 | 一句话"讲给我听" + 点亮星星 |
| **实践** | 任务卡（在模拟器、星盘或技术面板里完成）→ 写三句结论 | 点亮星星 |
| **案例** | 盘面事实（App 列出，飞飞核对）→ 按流程写解读要点 → 对照参考解读与传记事实 → 记一条心得 | 心得进入案例笔记 |
| **复盘** | 本周推导链排序 → 混合题 → "讲给我听"（可录音）→ 要点自评 | 每阶段最后一次复盘生成证书卡 |

## 4. 课程屏类型

| 类型 | 用途 | 样子 |
|---|---|---|
| **钩子屏** | 开头抛出问题 | 一个大问题，如"为什么偏偏是 12？" |
| **观察屏** | 天文事实 | 可拖动的小模拟（天文标签） |
| **推导屏** | 一步步推 | 每点一下出现下一步，最后高亮结论；像数学题的"解：" |
| **类比屏** | 比喻 | 左边日常场景，右边天文/占星概念，中间连线；底部一行"这个类比在哪里不成立" |
| **例子屏** | 具体数字或案例 | 一个算例或一张盘的局部 |
| **约定/争议屏** | 说清人为选择 | 并列不同流派的做法和理由 |
| **互动屏** | 动手 | 拖行星、转圆盘、调倾角、拖时间 |
| **反事实屏** | "如果……会怎样" | 拖滑块看结果变化 |
| **文献屏** | 原典摘句 | 托勒密、瓦伦斯、李利等的中文译述 + 出处 |
| **连线屏** | 与旧知识连起来 | 知识星网局部，新星亮起、连线画出 |
| **小结屏** | 本课结论 | 3 条以内，带标签 |
| **周易侧卡** | 可选桥接 | 折叠小卡，可在设置里整体关闭 |

## 5. 题型

| 题型 | 例子 |
|---|---|
| 单选回忆 | 春分点在黄经几度？ |
| **分步推导** | "狮子是第 5 个，求极性、元素、模式"，逐步作答，每步都判对错 |
| **步骤排序** | 打乱的推导链排好 |
| **找错** | "夏天热是因为离太阳近"——错在哪一步？ |
| **反事实** | 黄道分 10 份还能有三分相吗？ |
| **事实还是约定** | 把句子拖进"天文/推导/传统/约定/争议"格子 |
| **计算** | 两颗行星的相位；福点；小限星座；大会合周期 |
| **圆盘操作** | 把火星拖到和太阳成三分的位置 |
| **读盘** | 在一张盘上点出"区分外的凶星""命主星" |
| **判卜卦** | 给一张卜卦盘，判断是否完成、通过什么方式 |
| **讲给我听** | 开放回答，显示要点清单自评（不联网判分） |
| **类比配对** | 把"超车"配到"逆行" |

推导题答错时，显示推导链断在哪一步，并提供"回到那一屏"链接；错题自动进错题本。

## 6. 温习与间隔重复

- 每课生成 3–6 张卡，学完即进入队列；每天开课前固定 3 分钟温习（复盘日 5 分钟）。
- 卡片类型：回忆卡、推导卡（正面"为什么……？"，背面推导链）、圆盘卡（在空白盘上点位置）、事实/约定卡、读盘卡（一张盘的局部）。
- 算法：沿用易学堂的莱特纳 5 盒（间隔 1、2、4、7、15 天），后期可加第 6、7 盒（30、60 天）以适应两年的长度。卡片总量会到几千张，所以每天只取到期卡中最多 15 张，其余顺延。
- 错题本：按阶段和"断在哪一步"分类。

## 7. 学习地图与知识星网

**学习地图"星路"**：一条弧形银河，17 个阶段是沿途的 17 个星座图案。每学完一课，该阶段图案里亮一颗星；阶段结束时连线点亮并泛金光。当前位置标"你在这里 · 第 N 天"；显示总进度"第 N / 700 天"。

**知识星网**：概念是星，推导关系是线。点一颗星：它从哪几颗推出、又推出了哪些、在哪几课出现过。没学过的星是暗轮廓。约 700 个概念节点。

## 8. 打卡"点亮一颗星"

- 学完一课 → 按"点亮今天的星" → 一颗星从中央飞到日历当天的位置，闪一下后定住。
- 日历是一块星空；连续打卡的日子之间自动连线。
- 每月月底，这个月的星星排成一个小图案（彩蛋）。
- 补课当天也点亮，但连续天数按真实日期算（与易学堂一致）。
- 每 100 天一枚"里程碑"印章。

## 9. 问答区

1. **问答库**：随阶段增长，目标约 1000 条。按阶段、主题、标签（事实/传统/争议）分类，本地搜索（支持拼音首字母）。每条用"为什么 → 结论 → 约定/争议"格式，末尾链接到相关课程屏。
2. **每课的"常见疑问"**：课程最后折叠 2–3 条。
3. **我的疑问本**：随时记下问题，可挂到某一课；输入时推荐相似条目；学到相关课程时提醒"你问过的这个，今天会回答"；可标"已弄懂"。
4. **讲解练习**：随机抽一个概念"讲给我听"，显示要点清单自评；可录音（只存本机），之后能回听对比。
5. **带上下文复制**（可选）：一键把问题和当前课程摘要复制到剪贴板，方便粘贴到外部 AI 助手追问。App 本身不调用外部接口，不保存密钥。

## 10. 星图工作台

| 工具 | 功能 | 首次用到 |
|---|---|---|
| 天空模拟器 | 拖日期、时间、地点看天空；图层：黄道、天赤道、星座边界、地平线 | 第 6 天 |
| 星盘 | 本命盘；切换宫位制、黄道（回归/恒星）、容许度方案；点任何元素看"这是什么、为什么" | 第 5 阶段 |
| 尊贵面板 | 每颗行星的守护、旺、三分、界、十度、计分、定位链 | 第 3 阶段 |
| 古典面板 | 区分、特殊点、恒星合相、产前朔望 | 第 6 阶段 |
| 时间面板 | 行运列表、回归盘、次限推运、太阳弧 | 第 9 阶段 |
| 时间主星面板 | 小限、法达、黄道释放（L1–L4）、主限 | 第 10 阶段 |
| 校正助手 | 事件表 + 候选时间评分 | 第 11 阶段 |
| 卜卦起盘 | 一键"此刻"起盘，自动列出判断前考量与代表星 | 第 12 阶段 |
| 择日扫描 | 设条件，扫描未来时间窗口 | 第 13 阶段 |
| 世俗面板 | 入境盘、大会合、日月食列表、占星地图 | 第 14 阶段 |
| 比对盘 | 双盘叠合、组合中点盘、戴维森盘 | 第 15 阶段 |

工具不上锁，但每个面板顶部提示"学过第 N 阶段后更容易看懂"。

## 11. 案例库

- 约 60 张 AA/A 级出生数据的盘，以已故历史人物为主；每张附来源、评级、传记要点（公开事实）。
- 飞飞可以添加自己和家人的盘（只存本机）。
- 每张盘下面有"案例笔记"，记录每次读这张盘的心得，并按日期排列。

## 12. 预测日记

- 记录：日期、预测内容、依据技术、到期日、可检验的标准。
- 到期提醒，揭晓时打分（命中/部分/落空），统计命中率并与基线比较。
- 第 9、10、12、14、16、17 阶段都会用到。

## 13. 设置

节奏提醒时间、宫位制默认、黄道（回归/恒星，恒星可选岁差值）、容许度方案、是否显示周易侧卡、减少动态效果、导出/导入备份。
